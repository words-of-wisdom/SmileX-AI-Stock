## Commit 3 — feat: 热门个股连板概率分析（规则评分）

**后端** `limit_up_service.py`
- 模块级 `calc_continuation(item) -> (概率, 因子列表)` 启发式评分（0-100，注释明确非模型预测）：
  - 连板高度基础分（1板20 / 2板30 / 3板35 / 4板32 / 5板+28）
  - 封成比=封板资金/成交额（≥1.0→30 / ≥0.6→26 / ≥0.3→20 / ≥0.15→14 / ≥0.05→8 / 缺→12）
  - 炸板次数（0→20 / 1→10 / 2→4 / ≥3→0）
  - 首封时间（≤09:31→20 / ≤10:00→16 / ≤10:30→12 / ≤13:30→8 / 更晚→4 / 缺→10）
  - 换手率（≤10%→+8 / ≤20%→+5 / ≤30%→0 / >30%→-6）、振幅（>10%→-4）
  - 结果 clamp 到 5..95。
- `get_list` 序列化时计算填充（读时即时算，历史日期同样可用，无需迁移）。
- Schema `LimitUpStockItem` 加 `continuation_probability: int | None`、`continuation_factors: list[ContinuationFactor] | None`（因子结构 `{type, value}` 供前端 i18n）。

**前端** `limit-up/index.vue`
- 连板数列后新增「连板概率」列：百分比 NTag（≥65 高/红、40-65 中/橙、<40 低/灰）+ NTooltip 悬停展示评分因子明细；支持客户端排序；`scroll-x` 1400→1500。
- i18n 三处同步：`zh-cn.ts` / `en-us.ts` 的 `page.aStock.limitUp` 段 + `app.d.ts` Schema（列名、高/中/低、封成比/炸板/首封/换手等因子文案）。
