## 总体方案

三大功能全部复用现有基础设施：资讯抓取（`BusinessNews`，16+ 源每 5 分钟同步）、analysis 异步落库生成模式（`submit_run` 三态 + 并发守卫）、APScheduler 调度（`scheduler/tasks/` + `@scheduled_task`）、LLM 单轮直调（`_run_llm`）。宏观数据与财报为全新模块。

---

### 一、AI 每日资讯分析（早盘 + 周日晚）

**后端**（`backend/modules/analysis/`）：
1. `schemas/analysis.py`：`ANALYSIS_TYPES` 加 `"news"`；`SESSION_TYPES` 加 `"weekly"`（周日晚）。news 类型只用 morning/weekly 两个时段。
2. `services/analysis_executor.py`：
   - 新增 news 专用 system prompt（2 套：morning/weekly），要求输出 JSON 含两组分类要点：`macro_industry_news`（宏观经济+行业资讯，≤10条）、`stock_news`（个股资讯，≤10条），每条含 {title, source, viewpoint, impact}；morning 取近 24h 资讯，weekly 取近 7 天资讯做周度复盘。
   - `_build_user_prompt()`：news 类型时资讯条数上限从 30 提到 60（保证 LLM 有足够素材筛选）；注入宏观指数段（见功能三）。
   - 复用 `submit_run`/`_execute_analysis`/并发守卫，无需新表。
3. `database/models/business/analysis.py`：仅更新 comment 注释（字段是 String，无 schema 变更）。
4. `scheduler/tasks/analysis_run.py`：新增 `news_morning_generate` cron `20,35 9 * * mon-fri`、`news_weekly_generate` cron `30 20 * * sun`（APScheduler 星期必须写 `sun`），复用同日去重逻辑。

**前端**：
- 新页面 `frontend/src/views/ai/news-analysis/index.vue`，NTabs 切 morning/weekly，复用 `analysis-report-panel.vue`（扩展支持 `analysisType='news'`：渲染两个分类列表卡片——「宏观/行业资讯」「个股资讯」，各≤10条）。
- 新增 API 封装（analysis 接口已参数化，主要是类型常量与前端 typings）。
- 菜单：sys_menu 新增「每日资讯分析」菜单 + 同码 BUTTON 权限行 + sys_role_menu 授权（参照记忆中菜单不可见排查清单），前端 routes.ts 同步。

### 二、企业财报获取/解读/预测（持仓自动 + 任意手动）

**后端**（新模块 `backend/modules/financial/`，endpoints/services/schemas）：
1. 数据获取 service：基于 akshare 财报接口（`stock_financial_abstract_ths`/`stock_yjbb_em` 系列）按股票代码拉取关键指标（营收/净利/同比/ROE/毛利率等最近 N 期），存新表 `business_financial_report`（stock_code, report_period, metrics JSON, fetched_at；按 code+period 唯一，upsert）。
2. AI 解读 service：复用 analysis 的 `_run_llm` 模式，prompt 输入财报指标 + 近期走势摘要，输出 JSON{quality_rating, highlights, risks, forecast} + markdown 解读报告，落新表 `business_financial_interpretation`（stock_code, report_period, status 三态, parsed_result JSON, ai_raw_response, error_msg）——异步提交模式与 AnalysisRun 一致。
3. 定时任务 `scheduler/tasks/financial_run.py`：
   - `financial_report_sync`：每周 `0 8 * * mon-fri` 检查持仓+策略信号标的，拉取新披露财报并自动触发 AI 解读。
   - 财报季（4/8/10 月）披露密集，同日去重防止重复解读。
4. Endpoints：`POST /financial/reports/{code}/fetch`（手动拉财报+提交解读，异步 run 返回 interpretation_id）、`GET /financial/interpretations`（列表：持仓股自动解读记录）、`GET /financial/interpretations/{id}`（详情）。

**前端**：
- 新页面 `frontend/src/views/ai/financial-analysis/index.vue`：顶部股票代码搜索（NSelect filterable 手输代码），主体为解读报告（结构化卡片：评级/亮点/风险/预测 + markdown 原文），下方「持仓股财报解读」列表。
- 菜单「财报分析」+ BUTTON 权限 + routes.ts。

### 三、宏观经济指数板块（CPI/M1/M2 等，中国+美国）

**后端**（新模块 `backend/modules/macro/`）：
1. `services/macro_fetcher.py`：akshare 宏观接口——中国：`macro_china_cpi_monthly`、`macro_china_money_supply`（M0/M1/M2）、`macro_china_ppi`/`macro_china_gdp` 等；美国：`macro_usa_cpi_monthly` 等。统一写入新表 `business_macro_indicator`（country CN/US, indicator_code cpi/m1/m2/ppi..., period, value, yoy, mom, released_at；country+code+period 唯一，upsert）。
2. `scheduler/tasks/macro_sync.py`：`macro.sync_all` cron `30 7 * * *`（每日一次，宏观数据月度发布，日频同步足够）。
3. Endpoints：`GET /macro/indicators`（country/indicator 筛选 + 最近 N 期序列，供图表）、`GET /macro/indicators/latest`（全指标最新值卡片）。
4. **注入 AI 分析**：`analysis_executor.py` 新增 `_collect_macro_context()`——取中美 CPI/M1/M2 最新 1-2 期，格式化为简洁文本段，注入 news 分析与 market 分析（大盘 morning/close）的 user prompt；LLM 失败时摘除该段降级重试（复用资讯段降级模式）。

**前端**：
- 新页面 `frontend/src/views/ai/macro/index.vue`：顶部中美切换 tab + 指标卡片（最新值/同比/环比），下方历史走势图表（ECharts 折线，项目已有依赖则复用）。
- 菜单「宏观指数」+ BUTTON 权限 + routes.ts。
