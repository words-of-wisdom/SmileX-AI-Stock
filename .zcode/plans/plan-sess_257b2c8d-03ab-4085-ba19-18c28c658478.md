# 研报采集 + 概览 + 研报策略实施计划

## 一、后端：研报采集模块 `backend/modules/research/`

仿照 `modules/financial/` 结构新建：

1. **Model**：`backend/database/models/business/report.py`
   - `BusinessResearchReport`：stock_code、stock_name、title、org_name（券商机构）、author、rating（评级）、rating_change、target_price、预测指标（predict_year/predict_eps/predict_pe JSON）、summary、industry、published_at、url（唯一约束去重）、created_at
   - `business/models/__init__.py` 导出
2. **采集**：`services/research_fetcher.py`
   - 用 akshare `stock_research_report_em`（东财个股研报，支持 symbol 参数按股票抓取）+ `stock_rank_forecast` 类接口补充；`asyncio.to_thread` 包裹（同 macro_fetcher 模式）
   - 按 url upsert 去重；record 转换与时间归一化参考 news_fetcher
3. **Service**：`services/research_service.py` — 分页列表（筛选：股票代码/名称、机构、评级、日期区间）+ 统计概览（近30天研报总数、评级分布、热门股票/机构 TOP、目标价均值）+ 手动同步触发
4. **Endpoint/Schemas/Router**：`endpoints/research.py`、`schemas/research.py`、`router.py`（prefix `/admin/research`，注意 router prefix 须空的坑——prefix 写在 router.py 内）
   - 接口：`GET /reports`（分页列表）、`GET /reports/stats`（概览统计）、`POST /reports/sync`（手动触发同步，可传股票代码列表）
   - 统一响应 `{ code, msg, data, request_id, err_code }` + 分页 `{ records, page, page_size, total, total_pages }`
5. **定时任务**：`backend/modules/scheduler/tasks/research_sync.py`
   - `@scheduled_task(cron="0 */4 * * *" ...)` 定时增量同步（优先持仓股+热门股研报）；`backend/main.py` 注册 import
