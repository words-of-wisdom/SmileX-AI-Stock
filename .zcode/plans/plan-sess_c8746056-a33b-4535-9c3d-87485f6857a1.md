# 大盘/板块分析接入近期资讯 + 新增早盘(9:20)分析时段

## 方案总览

在现有 market/sector 两类分析之上引入**时段(session)维度**：`close`(收盘分析，默认，兼容存量) / `morning`(早盘分析，9:20)。大盘与板块两页各加「收盘分析 / 早盘分析」tab；收盘与早盘分析的数据输入统一追加**近24小时重点资讯**（复用已有 `BusinessNews` 表，5分钟一同步，无需新增抓取）。

## 一、后端

### 1. 数据库模型 + 迁移 0024
- `backend/database/models/business/analysis.py`：
  - `BusinessAnalysisRun` 增加 `session: str = "close"`（close-收盘，morning-早盘）
  - `BusinessAnalysisConfig` 增加 `session: str = "close"`；唯一索引由 `analysis_type` 改为 `(analysis_type, session)`
- 新迁移 `0024_add_analysis_session.py`：两表加列（server_default 'close'，存量数据自动归为收盘）、重建 config 唯一索引（注意 alembic bulk/JSON 坑按既有惯例规避）

### 2. Schema（`modules/analysis/schemas/analysis.py`）
- `SESSION_TYPES = ("close", "morning")` + `SESSION_TYPE_NAMES = {"close": "收盘分析", "morning": "早盘分析"}`
- `SessionQuery` Annotated+BeforeValidator（空/非法归 None 的既有模式）
- `AnalysisRunItem`、`AnalysisConfigItem` 增加 `session` 字段

### 3. 接口（`modules/analysis/endpoints/analysis.py`）
- `run / config(GET,PUT) / latest / runs` 五个接口统一增加 `session: str = Query("close")` 参数，非法值报错；查询与提交均带 session 过滤

### 4. 配置服务（`analysis_config_service.py`）
- `get_config / get_effective / update_config` 增加 session 参数，按 `(analysis_type, session)` 定位/新建配置

### 5. 执行器（`analysis_executor.py`）——核心
- `submit_run(db, analysis_type, trigger_type, session="close")`：并发守卫与落库均带 session（同类型不同时段可并行生成）
- 新增 `_collect_recent_news(db, hours=24, limit=30)`：查 `BusinessNews`（`published_at >= now-24h`，按时间倒序取30条），格式化为「标题｜源｜摘要」文本段；market/sector、close/morning 的数据收集统一追加该资讯章节
- 新增早盘系统提示词 `_MARKET_MORNING_SYSTEM_PROMPT` / `_SECTOR_MORNING_SYSTEM_PROMPT`：定位为"早盘前瞻"，数据=昨日收盘快照+近期资讯，侧重隔夜消息面对今日开盘影响、竞价观察要点、今日关注方向；JSON 摘要结构复用现有字段（`tomorrow_outlook` 在早盘语境为"今日展望"，前端按时段换标签），报告结构建议：
  - market：## 隔夜要闻解读 / ## 昨日市场回顾 / ## 今日开盘展望（情景推演+确认信号）/ ## 今日关注要点
  - sector：## 隔夜要闻与板块映射 / ## 昨日板块轮动回顾 / ## 今日主线推演 / ## 今日关注要点
- `_build_system_prompt(analysis_type, session, include_tomorrow)` 按 session 选择提示词组；早盘的研判章节（今日展望框架）对应改写一版
- `_analyze` 全链路透传 session

### 6. 定时任务（`modules/scheduler/tasks/analysis_run.py`）
- 现有 `analysis.auto_generate`（16:05）传 `session="close"`，去重条件加 session
- 新增 `analysis.morning_generate`：cron `20 9 * * mon-fri`，task_key 独立，同日同类型同时段去重，依次生成 market/sector 早盘分析（早盘资讯依赖 news.sync_all 每5分钟同步，无需排序依赖）

### 7. 种子脚本（`backend/scripts/seed_analysis_strategy.py`）
- 为 market/sector × morning 补种高水准早盘分析提示词（幂等 upsert）

## 二、前端

### 1. 类型与 API
- `typings/api/analysis.d.ts`：`SessionType = 'close' | 'morning'`；Run/Config 增加 `session` 字段
- `service/api/analysis.ts`：run/latest/runs/config 四组函数增加可选 `session` 参数（query 传递，缺省不传=收盘）

### 2. 共用报告面板（`views/ai/components/analysis-report-panel.vue`）
- 新增 prop `session: SessionType`，所有 API 调用透传
- 明日研判标签按时段切换：close=「明日研判」、morning=「今日研判」；策略抽屉标题也按时段区分（收盘/早盘策略）

### 3. 页面 tab（`market-analysis/index.vue`、`sector-analysis/index.vue`）
- 右侧报告区顶部加 `NTabs`：「收盘分析」(默认) /「早盘分析」，切换即换面板 session（`v-if` 或 key 强制重建面板以重置轮询/历史状态）；左侧行情数据栏不变

### 4. i18n（`locales/langs/zh-cn.ts`、`en-us.ts`）
- 新增 key：sessionClose、sessionMorning、morningOutlookLabel(今日研判) 等少量
